# Capítulo 00 — Como estudar para se tornar um especialista em Vue 3

> Objetivo: definir a metodologia oficial utilizada durante todo este material.

## O que significa ser especialista?

Ser especialista não é decorar APIs, mas compreender profundamente:
- O problema que cada API resolve.
- Como ela funciona internamente.
- Como foi implementada.
- Quando usar e quando evitar.
- Quais são suas limitações.

## Metodologia de estudo

Para **todo capítulo** siga esta sequência:

1. Leia o capítulo completo.
2. Reescreva o conteúdo com suas palavras.
3. Faça todos os exercícios.
4. Resolva o desafio proposto.
5. Implemente o projeto da seção.
6. Revise em 24 horas.
7. Revise novamente após 7 dias.
8. Explique o conteúdo para outra pessoa.

## Método Feynman

Ao terminar um assunto responda sem consultar material:

- O que é?
- Por que existe?
- Como funciona?
- Quando usar?
- Quando não usar?
- Como o Vue implementa?
- Como comparar com outras soluções?

## Como utilizar IA

Utilize IA para:
- esclarecer dúvidas;
- gerar exercícios;
- revisar conceitos;
- simular entrevistas;
- explicar o código-fonte.

Nunca utilize IA apenas para obter respostas prontas.

## Como estudar documentação

Sempre siga esta ordem:

1. Guia oficial
2. Referência da API
3. RFC correspondente
4. Código-fonte

## Como medir domínio

Considere um assunto dominado apenas quando conseguir:

- Explicar sem consultar documentação.
- Resolver problemas inéditos.
- Ensinar outra pessoa.
- Aplicar em projetos reais.
- Comparar alternativas.
- Identificar limitações.
